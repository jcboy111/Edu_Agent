# 什么是奇函数
好问题！你刚才已经观察了生活中的对称现象，现在让我们把这个想法用到数学上。
## 像"原点对称"这样的数学对称
**奇函数**的核心特点是：**图像关于原点对称**
让我说得更具体一些：
> 想象把坐标平面绕着原点（0,0）旋转180度，如果函数的图像和自己重合了，这就是一个奇函数。
## 举个例子
拿最简单的函数 $f(x) = x$ 来说：
- 取 $x = 1$，得到 $f(1) = 1$
- 取 $x = -1$，得到 $f(-1) = -1$
你发现了什么？
$$f(-x) = -f(x)$$
这就是奇函数的**代数定义**。
再比如 $f(x) = x^3$：
- $f(2) = 8$
- $f(-2) = -8$
同样满足 $f(-2) = -f(2)$。

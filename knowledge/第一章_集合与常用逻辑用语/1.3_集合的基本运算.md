# 1.3 集合的基本运算

## 知识点定义

### 并集（Union）
- **定义**：由所有属于集合A**或**属于集合B的元素组成的集合
- **符号**：$A \cup B$（读作"A并B"）
- **数学表达**：$A \cup B = \{x \mid x \in A, \text{或} x \in B\}$
- **Venn图**：阴影部分为A ∪ B

### 交集（Intersection）
- **定义**：由所有属于集合A**且**属于集合B的元素组成的集合
- **符号**：$A \cap B$（读作"A交B"）
- **数学表达**：$A \cap B = \{x \mid x \in A, \text{且} x \in B\}$
- **Venn图**：阴影部分为A ∩ B

### 补集（Complement）
- **全集**：含有所研究问题中涉及的所有元素的集合，记作U
- **定义**：由全集中不属于集合A的所有元素组成的集合
- **符号**：$\complement_U A$（读作"A在U中的补集"）
- **数学表达**：$\complement_U A = \{x \mid x \in U, \text{且} x \notin A\}$
- **Venn图**：U内A之外的区域

### 运算性质
1. **幂等律**：$A \cup A = A$；$A \cap A = A$
2. **同一律**：$A \cup \varnothing = A$；$A \cap \varnothing = \varnothing$
3. **交换律**：$A \cup B = B \cup A$；$A \cap B = B \cap A$
4. **结合律**：$(A \cup B) \cup C = A \cup (B \cup C)$
5. **德·摩根律**：$\complement_U(A \cup B) = \complement_U A \cap \complement_U B$

## APOS阶段标注

### Action（操作）阶段
学生能：
- 根据定义求两个集合的并集、交集、补集
- 用数轴或Venn图辅助计算

### Process（过程）阶段
学生能：
- 理解并集、交集的本质（"或"与"且"）
- 理解补集需要指定全集
- 运用运算律简化计算

### Object（对象）阶段
学生能：
- 将集合运算作为对象进行操作
- 处理复合运算（如 $A \cup B \cap C$）
- 用Venn图分析复杂关系

### Schema（图式）阶段
学生能：
- 用集合运算解决实际问题
- 理解集合论在数学中的基础地位

## 典型例题

### 例1：并集运算
**题目**：设 $A = \{4, 5, 6, 8\}$，$B = \{3, 5, 7, 8\}$，求 $A \cup B$

**答案**：
$$A \cup B = \{3, 4, 5, 6, 7, 8\}$$
（注意：5和8重复，只出现一次）

### 例2：交集运算
**题目**：设 $A = \{2, 4, 6, 8, 10\}$，$B = \{3, 5, 8, 12\}$，求 $A \cap B$

**答案**：
$$A \cap B = \{8\}$$

### 例3：补集运算
**题目**：设 $U = \{x \mid x \text{是小于9的正整数}\}$，$A = \{1, 2, 3\}$，求 $\complement_U A$

**答案**：
$$U = \{1, 2, 3, 4, 5, 6, 7, 8\}$$
$$\complement_U A = \{4, 5, 6, 7, 8\}$$

### 例4：综合运算（适合GeoGebra演示）
**题目**：设 $A = \{x \mid -1 < x < 2\}$，$B = \{x \mid 1 < x < 3\}$，求 $A \cup B$

**答案**：利用数轴可视化
$$A \cup B = \{x \mid -1 < x < 3\}$$

## 常见错误
1. 并集重复元素未去重
2. 交集与并集混淆（"或"vs"且"）
3. 补集运算遗漏全集定义
4. 复合运算顺序错误

## 教学建议
- **GeoGebra动态演示**：让学生拖动圆，观察交集/并集变化

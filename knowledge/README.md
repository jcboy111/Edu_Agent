# 知识库结构说明

## 目录结构

```
knowledge/
├── 第一章_集合与常用逻辑用语/
│   ├── 1.1_集合的概念.md          # 集合定义、表示方法、数集符号
│   ├── 1.2_集合间的基本关系.md    # 子集、真子集、集合相等、空集
│   ├── 1.3_集合的基本运算.md       # 并集、交集、补集、运算律
│   └── 1.4_充分条件与必要条件.md  # 充分条件、必要条件、充要条件
│   └── 1.5_全称量词与存在量词.md  # 全称量词、存在量词、命题否定
└── prompts/                        # Prompt模板（待创建）
```

## 文件格式规范

每个知识点文件包含以下部分：

1. **知识点定义** - 标准教材定义，可用于RAG检索
2. **APOS阶段标注** - 四阶段（Action/Process/Object/Schema）的学习目标
3. **典型例题** - 带答案的典型题目
4. **常见错误** - 学生容易犯的错误
5. **GeoGebra配置** - 动态图形生成参数
6. **苏格拉底引导模板** - 根据APOS阶段的自适应引导语

## APOS阶段说明

| 阶段 | 描述 | 学生表现 |
|------|------|----------|
| Action | 操作 | 能按步骤执行、会模仿 |
| Process | 过程 | 理解本质原理、能解释 |
| Object | 对象 | 把知识当整体使用 |
| Schema | 图式 | 综合应用、解决新问题 |

## GeoGebra使用方式

每个知识点文件中的GeoGebra配置是JavaScript代码片段，用于生成动态图形。

在MVP阶段，可以：
1. 预先生成静态图片嵌入回答
2. 或使用GeoGebra Classic的嵌入URL动态加载

## 知识库更新流程

1. 新增知识点 → 创建新的.md文件
2. 更新知识点 → 修改对应.md文件
3. 重建索引 → 重新向量化并存储到Qdrant

## 一、学情追踪Agent（后续）

### 1.1 追踪内容

| 追踪内容 | 优先级 | 说明 |
|----------|--------|------|
| 知识点掌握情况 | 高 | 学生学过了哪些知识点，哪些掌握得好 |
| APOS进度 | 高 | 学生在各知识点的APOS阶段 |
| 错题记录 | 中 | 学生问过哪些问题，答错了什么 |
| 学习轨迹 | 中 | 学生和AI的完整对话历史 |

### 1.2 用途

| 用途 | 说明 |
|------|------|
| 调整APOS判断 | 学生之前是Action阶段，现在问题更复杂可能是Process |
| 推荐学习路径 | 建议下一步学什么 |
| 个性化内容 | 根据历史调整讲解深度和习题难度 |

### 1.3 预留数据字段（MVP）

```python
class StudentProfile:
    student_id: str              # 学生ID
    knowledge_progress: Dict[str, str]  # 知识点 -> APOS阶段
    history_questions: List[str]  # 历史提问
    error_records: List[dict]    # 错题记录
```

## 三、Supervisor细化需求（已确认）

### 3.1 性格特征
- 温和鼓励 + 严谨逻辑

### 3.2 教学环节
- 核心：概念讲解 + 习题讲解
- 备选：错题分析、知识点回顾、课堂小结、学习方法指导、激发兴趣

### 3.3 交互方式
- 先肯定再引导 + 举例类比

### 3.4 解答困惑
- 换种方式讲 + 拆解问题

### 3.5 多模态
- 暂时不在Prompt里定义，在工具层实现
- GeoGebra动态图形、TTS语音等

## 四、智能体风格切换（后续）

### 4.1 三种人设

| 人设 | 适配学生 | 语气 | 讲解逻辑 | 画板配合 | 适配场景 |
|------|---------|------|----------|---------|---------|
| **人设1：温柔耐心导师** | 基础薄弱、畏难学生 | 温和舒缓、包容容错 | 拆分最小步骤、铺垫基础、避免跳跃 | 主动提示画图位置、基础参数调整 | 新课微课、基础错题纠正、基础概念 |
| **人设2：严谨竞赛学霸** | 拔高生、深挖逻辑 | 精炼客观、逻辑严密 | 深挖本质、定理推导、反例陷阱、分类讨论 | 引导自主探究参数极值、临界位置 | 函数深挖、抽象函数、高阶错题 |
| **人设3：趣味活力助教** | 注意力弱、抵触枯燥 | 年轻化轻松口语、趣味场景 | 生活化建模、兴趣案例包装 | 拖拽玩转图像、趣味话术解释 | 兴趣微课、趣味陪练、消除厌学 |

### 4.2 切换方式
- 首次使用时选择
- 后续在设置里修改

### 4.3 实现方式
```python
class StudentProfile:
    teacher_persona: str  # "gentle" / "rigorous" / "fun"
    ...
```

### 4.4 为什么需要切换
- 匹配不同学生的喜好和学习风格
- 提高学生参与度和学习效果
- 个性化教学体验

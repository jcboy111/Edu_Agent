## 二、Agent设计（已确认）

### 4个Agent节点
```
Supervisor（虚拟教师）→ APOS判断 → 知识检索 → 策略生成
```

### Supervisor定位
- 虚拟教师，模拟真实上课场景
- 性格：温和鼓励 + 严谨逻辑
- 教学环节：概念讲解 + 习题讲解
- 交互方式：先肯定再引导 + 举例类比
- 解答困惑：换种方式讲 + 拆解问题

### 智能体风格切换（后续）
| 人设 | 适配学生 |
|------|---------|
| 温柔耐心导师 | 基础薄弱、畏难学生 |
| 严谨竞赛学霸 | 拔高生、深挖逻辑 |
| 趣味活力助教 | 注意力弱、抵触枯燥 |

### APOS判断
- 输入：当前问题 + 同一次对话历史（最近3-5轮）
- 输出：APOS阶段 + 置信度 + 判断理由

### GeoGebra（增强）
- 集成在策略生成节点中
- 支持4种交互场景：venn、function、interval、geometric
- 预制 + 动态生成混合
- 强制联动：函数图像、区间划分、分类讨论、数形转化

## 三、产品设计（已确认）

### 页面架构
```
首页（方案B + 左侧导航栏）
    └── 对话页面（左右分栏）
        ├── 虚拟讲师文字区
        ├── 动态绘板区
        └── 互动应答区

预留页面
    ├── 完整微课堂
    ├── 学习历史
    ├── 题型练习
    └── 学习报告
```

### 首页布局（方案B）
- 大视觉冲击型
- 中心聚焦品牌感
- 左侧可隐藏导航栏

### 导航栏功能
- 🏠 首页 | 📚 章节 | ✍️ 练习 | 📊 报告 | ⚙️ 设置

### 对话页面布局
- 左右分栏：左边虚拟讲师文字区，右边动态绘板区
- 下方互动应答区
- 动态绘板区支持三种模式：动态课件/几何绘板/随堂练习
- 智能体与绘板联动：同步讲解、圈重点、分步引导

### UI风格
- 整体风格：科技感 + 学术感
- 主题：深色/浅色可切换
- 主色调：浅蓝色（#4A90D9）

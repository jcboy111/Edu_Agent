## 四、对话页面设计

### 4.1 左右分栏布局

```
┌─────────────────────────────────────────────────────────────┐
│ ☰  │  对话页面 - 定制化互动微课堂              [人设▼]  │
├────┼──────────────────────────────────────────────────────┤
│    │                                                        │
│ 导 │  ┌─────────────────────────────────────────────┐   │
│    │  │         动态课件 / 几何绘板 / 随堂练习       │   │
│ 航 │  └─────────────────────────────────────────────┘   │
│    │                                                        │
│ 栏 │  ┌──────────────────┐  ┌──────────────────────┐   │
│    │  │                  │  │                      │   │
│    │  │   虚拟讲师文字区  │  │     GeoGebra画板     │   │
│    │  │                  │  │                      │   │
│    │  │   AI分步讲解      │  │   - 同步高亮重点    │   │
│    │  │   圈出关键步骤    │  │   - 分步构建演示    │   │
│    │  │   文字配合图形    │  │   - 可拖拽参数      │   │
│    │  │                  │  │   - 边长/角度标注  │   │
│    │  │                  │  │                      │   │
│    │  └──────────────────┘  └──────────────────────┘   │
│    │                                                        │
│    │  ┌─────────────────────────────────────────────┐   │
│    │  │  互动应答区                                  │   │
│    │  │  [文字输入] [快捷按钮] [打断机制]          │   │
│    │  └─────────────────────────────────────────────┘   │
│    │                                                        │
└────┴──────────────────────────────────────────────────────┘
```

### 4.2 对话页面功能模块

| 模块 | 功能 |
|------|------|
| 虚拟讲师文字区 | 文字推演、分步讲解、AI引导、圈出重点 |
| 动态绘板区 | GeoGebra交互、三种模式切换 |
| 互动应答区 | 学生打断、质疑、提问、AI实时应答 |

### 4.3 动态绘板区 - 三种模式

| 模式 | 功能 | 界面特点 |
|------|------|---------|
| **动态课件** | 类似PPT分页展示+GeoGebra演示 | 左侧内容+右侧图形+播放控制 |
| **几何绘板** | 纯GeoGebra，可拖拽操作 | 纯图形+GeoGebra工具栏 |
| **随堂练习** | 左侧题目+右侧GeoGebra | 可交卷、批改 |

### 4.4 智能体与绘板联动

| 联动功能 | 说明 |
|----------|------|
| 同步讲解 | 智能体文字输出时，绘板区同步高亮/标注重点 |
| 圈出重点 | 在图形上标注关键元素 |
| 分步引导 | 分步骤展示几何构建过程 |
| 参数联动 | 文字讲解时图形参数实时变化 |

## 四、知识大地图

### 4.1 节点类型

| 节点类型 | 状态标识 | 视觉表现 |
|----------|----------|----------|
| 章节（父节点） | - | 大圆/六边形，点击展开 |
| 知识点（子节点） | - | 小圆/六边形 |
| 当前推荐 | NEXT | 呼吸灯光效 + 闪烁外圈 + 高亮路径 |
| 已掌握 | ✓ | 金色/亮蓝色 + 对勾 |
| 进行中 | 进度% | 蓝色 + 进度条 |
| 未解锁 | 🔒 | 灰色 + 锁图标 |

### 4.2 地图结构（人教版必修一）

```
第一章：集合与常用逻辑用语 ──→ 第二章：一元二次函数、方程和不等式
                                        │
                                        ↓
                              第三章：函数概念与性质 ←── 第四章：指数函数与对数函数
                                        │
                                        ↓
                              🌟 3.2 函数的基本性质 (NEXT)
                                        │
                                        ↓
                              3.1 函数的概念及其表示
                                        │
                                        ↓
                              第五章：三角函数（远方区域）
```

### 4.3 交互逻辑

- **缩放/拖拽**：支持鼠标滚轮缩放、拖拽移动
- **点击父节点**：地图平滑缩放，聚焦并展开该章节
- **点击子节点**：弹出右侧浮动卡片
- **推荐路径**：从起点到当前推荐节点路径高亮

## 七、UI设计规范

### 7.1 整体风格
- **设计理念**：数学探索之旅（Math Exploration Odyssey）
- **视觉风格**：现代、轻科技感、微立体或干净扁平化

  }
  50% {
    box-shadow: 0 0 25px rgba(74, 144, 217, 0.8);
  }
}

  animation: breathe 2s ease-in-out infinite;
}

## 十二、智能辅导页面

> 最后更新：2026-05-01

### 12.1 页面定位

苏格拉底式引导学习界面，通过"左侧知识空间 + 右侧对话流"的双栏布局，实现启发式教学。

### 12.2 布局结构

```
┌────────────────────────────────────────────────────────────────────┐
│ ☰  │  智能辅导                    [人设▼]                          │
├────┼──────────────────────────────────────────────────────────────┤
│    │  ┌──────────────────────────────────┐  ┌──────────────────┐  │
│ 导 │  │  📝 学生提问                     │  │  👩‍🏫 AI导师     │  │
│    │  │  "解方程：x² - 5x + 6 = 0"     │  │  引导式学习助手  │  │
│ 航 │  ├──────────────────────────────────┤  │  [📝文字] [🎤语音]│  │
│    │  │                                  │  ├──────────────────┤  │
│ 栏 │  │  AI 解题空间                     │  │                  │  │
│    │  │  ┌────────────────────────────┐ │  │  👩‍🏫: 你能告诉我  │  │
│    │  │  │ ① 概念 → ② 定理 → ③ 公式  │ │  │  这个方程的a、b、│  │
│    │  │  │ ④ 计算 → ⑤ 解释           │ │  │  c分别是什么吗？ │  │
│    │  │  └────────────────────────────┘ │  │                  │  │
│    │  │                                  │  │  用户: a=1,b=-5  │  │
│    │  │  [📐] [🔍]  ← 悬浮按钮         │  │  c=6             │  │
│    │  ├──────────────────────────────────┤  │                  │  │
│    │  │  📷 🖼️ 🎤                       │  │  👩‍🏫: 很好！那   │  │
│    │  │  [输入你的回答或提问...    ]➤  │  │  谁能观察...     │  │
│    │  │  💡 支持多模态输入·实时打断    │  │                  │  │
│    │  └──────────────────────────────────┘  └──────────────────┘  │
└────┴──────────────────────────────────────────────────────────────┘
```

### 12.3 左侧工作区

**顶部：学生问题卡片**
- 显示学生提交的问题或从虚拟课堂跳转来的题目

**中部：AI解题空间**（分步卡片流）
- 步骤类型标签：概念（蓝）、定理（紫）、公式（绿）、计算（橙）、解释（粉）
- 每个步骤包含：序号圆点 + 连接线 + 内容卡片
- 内容卡片包含：类型标签 + 标题 + 详细文字/公式

**悬浮按钮**（右下角）
- 📐：打开GeoGebra画板（弹窗选择工具类型）
- 🔍：知识点溯源（弹窗显示知识路径图）

### 12.4 右侧对话区

**头部**
- AI导师头像 + 名称 + 在线状态
- 文字/语音模式切换按钮

**对话流**
- AI消息气泡（灰色，左对齐）+ 用户消息气泡（蓝色，右对齐）
- 每条消息带时间戳

**底部输入区**
- 工具栏：📷拍照、🖼️上传、🎤语音
- 文本输入框 + 发送按钮
- 提示文字：支持多模态输入·实时打断

### 12.5 弹窗功能

**GeoGebra 弹窗**
- 工具选择：函数图像、几何图形、Venn图、数轴区间
- 占位提示区

**知识点溯源弹窗**
- 知识路径图：节点 + 连接线展示知识点关联
- 解题路径总结

### 12.6 后续动态化计划

| 功能 | 说明 | 状态 |
|------|------|------|
| 分步展示 | 根据学生响应逐步显示解题步骤 | 后续开发 |
| 自适应步骤 | 不同题目类型有不同的步骤组合 | 后续开发 |
| APOS控制 | 根据学情诊断状态控制显示逻辑 | 后续开发 |
